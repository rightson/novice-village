## 🗺️ 怎麼使用這些教材

1. **先挑一個主題**：從上面的清單選一個你現在最需要的。
2. **照章節順序看**：每份教材都從基本概念開始，循序漸進。
3. **動手做一次**：看完後找個測試環境實際操作，記得最牢。
4. **卡住了就問**：遇到問題，開一個 [Issue](../../issues) 問大家吧！

### 🧭 Jira 教材的建議讀法

- **一般成員**：先看「01 核心概念」→「03 日常操作」→「04 查詢與衡量」，就能應付每天的工作。
- **帶領團隊的人**：再加讀「02 團隊規劃」與「05 企業管理與治理」。
- **想馬上上手**：直接跳到「06 實作與速查」，跟著 30 分鐘實作走一遍。

## 🤝 一起讓新手村更熱鬧
